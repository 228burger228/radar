# 🥄 Солянка с ложкой | Радар ИИ (Radar AI)

Кураторская база топовых GitHub-репозиториев, боевых системных промптов, архитектурных выжимок (TL;DR) и интерактивного Джарвис-ядра с локальной памятью.

## 🌟 Ключевые возможности

1. **🧭 GitHub AI Radar:**
   - Отборные репозитории: автономные агенты (`Hermes-Agent`, `oh-my-claudecode`), голосовой стек (`Whisper.cpp`, `Silero VAD`, `VoiceStudio`, `Porcupine`), утилиты и дизайн-системы.
   - Выжимка за 30 секунд (TL;DR) и объяснение «Зачем брать».
   - Копирование команд быстрого запуска в 1 клик.

2. **⚡ Промпт-Кузница (Prompt Forge):**
   - Боевые системные промпты (Anti-Slop чистый код, GEO-аудит под Perplexity/Gemini/ChatGPT, верификаторы агентных циклов).

3. **🎓 AI Академия:**
   - Выжимки практических архитектур: автономный голосовой агент оффлайн, RAG без тяжелых библиотек, правила «Бизнес-Премиум» дизайна.

4. **🤖 Джарвис-Ядро & Локальная память:**
   - Интеллектуальный поиск на естественном языке по всей базе солянки.
   - Хранение закладок и пользовательских находок в `localStorage` (без серверных зависимостей).
   - Экспорт всей базы в единый JSON-файл в 1 клик.

## 🚀 Быстрый запуск

Проект написан на чистом **Vanilla JS / CSS3 / HTML5** — никаких `npm install`, сборщиков или тяжелых фреймворков.

Просто откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js npx
npx serve .
```
